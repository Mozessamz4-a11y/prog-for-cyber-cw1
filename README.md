## Introduction
This Python program demonstrates how login attempts can be monitored using security event logs.

## Features
- Username and password authentication
- Successful and failed login events
- Event ID for each login attempt
- Username and example IP address
- Event type and timestamp
- Repeated login attempts until successful

## How to Run
Open the terminal and enter:

`py security_event_logger.py`
