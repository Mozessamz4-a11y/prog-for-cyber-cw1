## Introduction
This Python program demonstrates how dictionaries can be used to manage information about security incidents.

## Features
- Creates a security incident dictionary
- Stores a username and IP address
- Stores an event type and risk level
- Adds an incident status
- Updates the risk level
- Removes an existing field
- Displays the remaining information
- Counts the remaining dictionary fields

## How to Run
Open the terminal and enter:

`py security_incident_manager.py`
